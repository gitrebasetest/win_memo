## Why

Windows 缺少一个足够轻量、可悬浮、同时兼顾提醒交互体验的本地备忘录工具。这个变更旨在提供一个基于本地存储的桌面备忘录应用，帮助用户录入带时间的事件，并在事件到达时通过动画提醒进行及时干预。

## What Changes

- 新增一个 Windows 桌面备忘录应用，支持悬浮显示与隐藏切换。
- 新增事件录入与编辑能力，支持为事件保存标题、内容、一次性时间点、重复提醒规则和提醒状态。
- 新增到点提醒能力，在事件时间到达时展示带动画效果的提醒弹窗。
- 新增提醒交互能力，允许用户关闭当前提醒或将提醒延后到新的时间。
- 新增规则化提醒能力，支持按工作日、按每周指定时间、按绝对日期时间进行提醒。
- 新增工作日判断能力，在需要时联网获取节假日信息，以识别法定工作日和节假日安排。
- 新增开机自动启动能力，使应用在 Windows 登录后自动运行并继续提醒调度。
- 新增基于 SQLite3 的本地持久化存储方案，用于保存事件、提醒规则与提醒记录。
- 新增 PyInstaller 打包支持，用于生成可分发的 Windows 可执行程序。

## Capabilities

### New Capabilities
- `desktop-note-window`: 提供可悬浮在桌面上的主窗口，并支持显示与隐藏切换。
- `event-scheduling`: 提供事件录入、编辑、删除、查询，以及一次性时间点和规则化时间驱动的提醒调度能力。
- `animated-reminders`: 在事件到达时展示动画提醒，并支持关闭和延后提醒。
- `holiday-aware-scheduling`: 提供工作日规则提醒所需的节假日联网判断与本地缓存能力。
- `startup-and-packaging`: 提供 Windows 开机自启、SQLite3 本地持久化以及 PyInstaller 打包发布能力。

### Modified Capabilities
- 无。

## Impact

- 受影响代码包括桌面 UI、提醒调度逻辑、本地数据库访问层与应用入口。
- 新增依赖和技术栈约束包括 Python、PyQt6、SQLite3 与 PyInstaller。
- 不涉及外部 API 或云端系统，所有数据默认保存在本地环境。
